# acme/feature-toggles-typo3

TYPO3 extension skeleton that wires `acme/feature-toggles-core` into TYPO3 DI.

## Setup

- Install via composer (path repo or VCS)
- Run DB compare to apply `ext_tables.sql`
- Configure defaults/environment in TYPO3 extension configuration (ExtensionConfiguration)

This is a skeleton; adapt config handling to your project conventions.
